# 🧠 Deep Learning Mini Projects

**Artificial Neural Network (ANN) | Convolutional Neural Network (CNN)**

Explore the fundamentals of deep learning through two practical projects: binary classification using an Artificial Neural Network and image classification using a Convolutional Neural Network.

---

## 📌 Projects Overview

### 1. ANN – Binary Classification

**Title:** Development of an Artificial Neural Network (ANN) for Binary Classification Using the `make_moons` Dataset from Scikit-learn

An Artificial Neural Network is developed to classify moon-shaped data points into two categories. The model learns patterns from the dataset using hidden layers and predicts the class of unseen data.

**Key Features**
- Generates a dataset using Scikit-learn's `make_moons`.
- Preprocesses data using feature scaling.
- Builds a neural network using TensorFlow and Keras.
- Uses ReLU and sigmoid activation functions.
- Evaluates the model using Accuracy, Precision, Recall, and F1-score.
- Visualizes evaluation metrics using a bar graph.

### 2. CNN – Dog and Cat Image Classification

**Title:** Development of a Convolutional Neural Network (CNN) for Dog–Cat Image Classification Using Three Convolutional Layers

A Convolutional Neural Network is developed to identify whether an image contains a dog or a cat. The model learns visual patterns from images and uses these features to predict the correct category.

**Key Features**
- Loads and preprocesses dog and cat images.
- Uses three convolutional layers for feature extraction.
- Applies max-pooling to reduce feature dimensions.
- Uses dense layers for classification.
- Evaluates performance using Accuracy, Precision, Recall, and F1-score.
- Displays evaluation results using a bar graph.

## 📊 Evaluation Metrics

Both projects use the following metrics to evaluate model performance:

| Metric | Description |
|---|---|
| Accuracy | Measures the proportion of correct predictions. |
| Precision | Measures how many positive predictions are correct. |
| Recall | Measures how many actual positive samples are identified. |
| F1-score | Combines precision and recall into a single score. |

The results are displayed in bar graphs for easy comparison and interpretation.
